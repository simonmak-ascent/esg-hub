# Contributing

## Setup

```bash
git clone https://github.com/simonmak-ascent/esg-hub.git
cd esg-hub
pnpm install
```

## Development

1. Create a feature branch from `main`
2. Make changes following project conventions
3. Verify: `pnpm check && pnpm test`
4. Open a PR against `main`

## Commit Conventions

- `feat:` new features
- `fix:` bug fixes
- `chore:` maintenance
- `docs:` documentation
- `perf:` performance

## Questions?

Open an issue. For security issues, see [SECURITY.md](./SECURITY.md).
